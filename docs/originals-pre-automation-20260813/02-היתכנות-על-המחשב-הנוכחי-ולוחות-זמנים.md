## מגבלות קריטיות
1. Quadro P2000 עם 5GB אינו מתאים למודלים המרכזיים.
2. compute capability 6.1 אינו תואם ל-wheel של MMCV ב-PanoWorld שנבנה ל-SM80/SM90.
3. Python 3.14 חדש מדי עבור חלק גדול מהתלויות; הפרויקט צריך Python 3.10/3.11 מבודד.
4. WSL מקבל כרגע כ-23GiB RAM בלבד, אך זה מספיק לפיתוח רגיל.
5. Blender אינו מותקן, ולכן יש להוסיף שלב setup נפרד כאשר תתחיל הבנייה.
6. דיסק D מספיק; אין לשמור datasets או Docker images כבדים ב-C.

## הערכת זמן כאשר סוכני AI כותבים את העבודה
הזמנים כוללים תכנון, כתיבה, בדיקות, reviews ותיקון אינטגרציות. סוכנים מקצרים כתיבת קוד, אך אינם מבטלים debugging, אימות גאומטריה ותכנון contracts.

ההערכה מניחה routing לפי `MODEL-ROUTING-v1`: Opus 5 ב-EXTRA/MAX למשימות 3D, OpenAI GPT-5.6/Codex ב-HIGH למשימות קוד ובדיקות, Fable 5 ב-EXTRA לתזמור ו-Haiku/Sonnet לעבודות קלות. שימוש במודל חזק אחד לכל המשימות לא יקצר את לוח הזמנים באופן לינארי, משום שהחסמים העיקריים הם אינטגרציה, fixtures, רינדור ובקרה אנושית.

### רמת POC — תוכנית אחת נקייה
מטרה: floorplan אחד → white model → cameras → depth/extrinsics → package תקין.

- 2–4 שבועות קלנדריים.
- 15–25 סבבי agent/review.
- 10–25 שעות פיקוח אנושי.
- אינו production-ready.

### MVP מקומי H200-ready
מטרה: pipeline מתוזמר, dashboard, validators, retries ו-mock remote runner.

- 8–12 שבועות קלנדריים.
- 35–60 סבבים מתועדים.
- 40–80 שעות פיקוח אנושי.
- לאחר מכן 1–2 שבועות integration/tuning מול H200 אמיתי.

### מערכת אמינה למספר סוגי תוכניות
- 4–8 חודשים.
- 80–150 סבבים.
- dataset פנימי של תוכניות בדיקה.
- human-in-the-loop, observability ו-security hardening.

## החלטת Go/No-Go מומלצת

### Go ל-POC מקומי אם:
- נבחרת תוכנית נקייה אחת עם מידות.
- מקבלים ששלב geometry approval יהיה ידני.
- מגדירים קלט/פלט מדויק לפני קוד.
- H200 נשכר רק לאחר package validator ירוק.

### No-Go זמני אם:
- מצפים לדיוק אדריכלי מתמונה ללא מידות.
- מצפים שה-5GB GPU יריץ את PanoWorld.
- אין נכונות לאישור אנושי בשלושה gates.
- אין dataset חוקי של תוכניות לבדיקות.

## המלצה
להתחיל ב-POC מקומי בן 3 שבועות על תוכנית אחת, תוך שימוש בסצנת PanoWorld קיימת כ-reference fixture. בסוף ה-POC צריכה להיות חבילת קלט שניתנת להשוואה אוטומטית למבנה הדוגמה. רק אם gate זה עובר, לפתוח שרת H200 לשלב integration.
