## Floorplan parsing

### CubiCasa5K
https://github.com/CubiCasa/CubiCasa5k
https://arxiv.org/abs/1904.01920

שימוש מוצע:
- segmentation של תוכניות raster.
- rooms, walls, doors, windows וקטגוריות נוספות.

מגבלות:
- stack ישן: Python/PyTorch/CUDA ישנים.
- דורש adapter ומודרניזציה.
- אינו יוצר package של PanoWorld.

> **עדכון 2026-08-18 — נדחה לשימוש.** הקוד הוא stack 2019 (Python 3.6 / PyTorch 1.0 / CUDA 9.0 / OpenCV 3.1) ומשקולותיו בקישור Google Drive; פלטו הוא segmentation masks (לא JSON של קירות). המוצר המסחרי של CubiCasa הוא SDK סלולרי (CubiCapture) לסריקת חדרים בטלפון — אינו API של תמונה→floorplan (`api.cubi.casa` מחזיר 404).

### FloorplanTransformation
https://github.com/art-programmer/FloorplanTransformation

מקור raster-to-vector שאליו CubiCasa מפנה. שימושי כ-reference לארכיטקטורת vectorization.

### ezdxf (CAD/DXF intake)
https://github.com/mozman/ezdxf
https://ezdxf.readthedocs.io/

שימוש מאומץ (2026-08-18):
- קריאה/כתיבה של DXF (`LWPOLYLINE`, `LINE`, `TEXT` ועוד) לשלב intake של מקורות CAD וקטוריים.
- גרסה 1.4.4, Python >=3.10; תלויות ליבה קלות (`pyparsing`, `numpy`, `fonttools`).
- ל-DWG נדרש ODA File Converter חיצוני (תוסף `odafc` של ezdxf).

אימות: round-trip חי (יצירה + קריאה) הורץ בהצלחה; תלות נעולה ב-`pyproject.toml` (`ezdxf>=1.4`).

### FloorplanToBlender3d
https://github.com/grebtsew/FloorplanToBlender3d

שימוש מוצע:
- baseline מהיר מתמונת floorplan ל-Blender.
- reference להפקת walls/rooms ול-API.

מגבלות:
- heuristic ורגיש לאיכות התוכנית.
- Docker מבוסס Ubuntu 18.04.
- commit פעילות קוד אחרונה שנמצאה: 2024.
- GPL-3.0; לבדוק השלכה על הפצה.

> **עדכון 2026-08-18 — רפרנס בלבד, לא העתקה.** GPL-3.0. הזיהוי הוא OpenCV היוריסטי (threshold/morphology/watershed — לא ML) ומהיר על חומרה חלשה; סקריפט ה-Blender נבדק על 2.93 (אצלנו 5.1). משמש כנקודת מוצא ללוגיקת זיהוי ובניית ה-mesh; אין העתקת קוד בשל הרישיון.

## 2D floorplan to 3D research

### HouseCrafter
https://github.com/neu-vi/houseCrafter
https://neu-vi.github.io/houseCrafter/
https://arxiv.org/abs/2406.20077

שימוש מוצע:
- reference מתקדם ל-floorplan-conditioned RGBD multi-view generation.
- מפיק RGB, depth ו-camera transformations הקרובים לחוליה שחסרה לפני PanoWorld.

מגבלות:
- דורש layout samples, rendered floor, graph poses ו-wall info — לא JPG גולמי בלבד.
- דורש GPU עם לפחות 24GB VRAM לפי הריפו.
- המחשב הנוכחי אינו מתאים להרצה מעשית.

### Plan2Scene
https://github.com/3dlg-hcvc/plan2scene
https://3dlg-hcvc.github.io/plan2scene/
https://arxiv.org/abs/2106.05375

שימוש מוצע:
- reference ליצירת 3D scene מתוכנית ומספר תמונות.
- texture propagation ו-object placement ideas.

מגבלות:
- דורש תוכנית + סט תמונות/נתוני Rent3D++, לא תמונת style אחת.
- pipeline מורכב ותלויות ישנות.

## Geometry ו-rendering

### Blender Python API
https://docs.blender.org/api/current/

שימוש מוצע:
- יצירת white model דטרמיניסטי.
- walls/floors/ceilings/openings.
- cameras, exports ו-headless rendering.

### Blender
https://www.blender.org/

רכיב geometry המרכזי. מומלץ לבחור גרסת LTS ולנעול אותה.

### BlenderProc
https://github.com/DLR-RM/BlenderProc
https://dlr-rm.github.io/BlenderProc/
https://arxiv.org/abs/1911.01911

שימוש מוצע:
- טעינת scene.
- camera poses.
- RGB, depth, normal ו-segmentation rendering.
- bridge ל-control assets של PanoWorld.

מגבלות:
- GPL-3.0.
- רץ בתוך סביבת Python של Blender.
- נדרשת בדיקת equirectangular output ופורמט depth מדויק.

### Blender MCP
https://github.com/ahujasid/blender-mcp
https://blendermcp.org/

שימוש מוצע:
- inspection ותיקון חריגים בידי סוכן.
- viewport screenshots.
- הפעלת Python בתוך Blender.

מגבלות ובטיחות:
- מאפשר arbitrary Python execution.
- לא להשתמש בו כמנוע batch העיקרי.
- יש לבודד network/permissions ולהגביל commands.

## כלים נוספים שנסקרו — 2026-08-18

בעקבות סריקת GitHub/HuggingFace/arxiv על שלבי הפייפלין והצלבת מחקר חיצוני מול המקור, נוספו המועמדים הבאים (כולם **[Candidate]** — דורשים spike/ADR):

### מועמדים לשלבים
- **Raster2Seq** (https://github.com/Cornell-VAILab/Raster2Seq) — MIT, 40★, פעיל 2026-07. מועמד ל-C3 (floorplan raster → פוליגונים וקטוריים). חדש וקטן — דורש spike (Linux/PyTorch 2.3.1/CUDA 11.8; custom C++/CUDA ops).
- **Building Tools** (https://github.com/ranjian0/building_tools) — MIT, 1502★. מועמד ל-C4 (walls/doors/windows/stairs/roofs ב-Blender). למחזר אלגוריתמים, לא להחליף את ה-domain model.
- **SkyPilot** (https://github.com/skypilot-org/skypilot) — Apache-2.0, 10502★, פעיל מאוד. מועמד ל-C10 (provision/upload/run/download/terminate). נדרש cost/TTL reaper עצמאי.
- **equilib** (https://github.com/haruishi43/equilib) — Apache-2.0, פעיל 2026-08. המרות equirectangular/cubemap/perspective (C6).
- **nvTorchCam** (https://github.com/NVlabs/nvTorchCam) — Apache-2.0, 156★. projection/unprojection (C6).
- **TorchMetrics** (https://github.com/Lightning-AI/torchmetrics) — Apache-2.0, 2459★. מדדי QA (C11).

### אזהרות רישוי
- **IQA-PyTorch / pyiqa** — PolyForm Noncommercial 1.0.0. לא למוצר מסחרי. חלופה: TorchMetrics (Apache-2.0).
- **MinIO** — AGPL-3.0; הריפו הועבר לארכיון באפריל 2026.
- **CubiCasa5K dataset** — CC BY-NC-SA 4.0 (קוד "Other"; ה-data מגביל שימוש מסחרי).
- **pyvispoly** — GPL דרך CGAL (נתיב הריפו המדויק לא אותר; זהירות כללית).

### תיקונים למסמך מחקר חיצוני
- **openPlan3D** (laanlabs/openPlan3D) — עורך 2D/3D ידני (SvelteKit + Three.js), לא מודל זיהוי מתמונה. מתאים לכל היותר לשכבת תיקון אנושי.
- **lab-camera-optimizer** (flodelaplace) — אופטימיזציית מצלמות ל-motion capture (ביומכניקה), לא לפנורמות. מיחזור אלגוריתמים גנריים בלבד (FOV/line-of-sight/coverage).
